# CamViewer 토큰 자동 갱신 정책

## 목적

CamViewer가 최초 로그인 후 저장한 토큰의 24시간 실행 만료 시각이 지나더라도,
매일 매장 ID와 비밀번호를 다시 입력하지 않고 온라인 상태 검증 후 새 토큰을 발급받는다.

## 갱신 허용 조건

`POST /api/viewer/verify-token`은 다음 조건을 모두 만족할 때만 만료 토큰을 갱신한다.

1. 토큰 형식과 HMAC-SHA256 서명이 정상이다.
2. 토큰 Payload를 정상적으로 복원할 수 있다.
3. 토큰의 `OfflineUntil`이 지나지 않았다.
4. 토큰이 CamViewer용이다.
5. 요청 HWID와 토큰 HWID가 일치한다.
6. `devices`에 해당 Viewer 장비가 존재한다.
7. 장비의 매장, HWID, 앱 유형이 토큰과 일치한다.
8. 매장이 활성 상태다.
9. 토큰이 참조하는 계약이 존재하고 해당 매장에 연결되어 있다.
10. 계약에 CamViewer 허용 수량이 있고 계약 상태와 기간이 유효하다.

모든 검증이 끝난 후에만 새로운 실행 토큰을 발급한다.

## 차단 조건

다음 경우에는 자동 갱신하지 않는다.

- 서명 위변조 또는 토큰 형식 오류
- `OfflineUntil` 만료
- HWID 불일치
- Viewer가 아닌 앱 토큰
- 장비 해제 또는 삭제
- 매장 비활성
- 계약 없음, 비활성 또는 만료
- CamViewer 허용 수량이 없는 계약

## 시간 정책

- 실행 토큰 만료: 기본 24시간
- CamViewer 오프라인 및 갱신 허용 기간: 기본 7일
- 온라인 검증 성공 시 실행 토큰과 7일 허용 기간을 현재 시각 기준으로 다시 발급
- PC CAM 오프라인 정책은 기존 설정을 유지

## API 범위

만료 토큰의 제한적 허용은 `verify-token`의 회전 발급 흐름에만 적용한다.
일반 `TokenService.ValidateToken()`을 사용하는 설정 API와 PC CAM API는 기존처럼 만료 토큰을 거부한다.
